      💾 数据管理

      所有数据保存在你当前浏览器本地（localStorage），不会上传到任何服务器。可随时导出备份或导入恢复。

      🧬 代谢测试 估算基础代谢与每日总消耗

      输入性别、年龄、体重、身高，自动按 Mifflin-St Jeor 公式计算 BMR，再结合活动量估算 TDEE。计算结果按「测试生效年月」写入对应月份的每日动态消耗（体重不同月份，动态消耗也不同）。

      📱 在手机上安装为 App

      部署到公网后，手机浏览器打开本页面即可「添加到主屏幕」，像原生 App 一样全屏使用、可离线打开。

      • iPhone / iPad：用 Safari 打开页面 → 点底部「分享」按钮 → 选「添加到主屏幕」→ 命名后「添加」。
      • 安卓：用 Chrome 打开页面 → 点右上「⋮」→「安装应用」/「添加到主屏幕」。
      • 换手机或重装后，先用上方「导出 JSON 备份」导出，新设备「导入 JSON 备份」即可恢复全部数据。

      ➕ 自定义食物

      登记一条今日饮食，保存后会同时加入「食物库」，方便以后快速选用。热量 / 营养为这条记录的实际数值。

      🏃 自定义运动

      登记一条今日运动消耗，保存后会同时加入「运动库」，可选无氧 / 有氧类型。

      📅 月热量记录
